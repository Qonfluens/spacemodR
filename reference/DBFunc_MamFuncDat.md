# Mammal Functional Traits Dataset (EltonTraits 1.0)

Dietary category percentages, foraging strategies, and functional traits
for mammals.

## Usage

``` r
DBFunc_MamFuncDat
```

## Format

A data frame containing species dietary breakdowns (summing to 100

- MSW3_ID:

  Mammal Species of the World (3rd ed.) identifier.

- Scientific:

  Scientific name of the mammal species.

- MSWFamilyLatin:

  Mammal Species of the World (3rd ed.) family name.

- Diet.Inv:

  Percentage of invertebrates in the diet.

- Diet.Vend:

  Percentage of vertebrate endotherms consumed (birds and mammals).

- Diet.Vect:

  Percentage of vertebrate ectotherms consumed (reptiles and
  amphibians).

- Diet.Vfish:

  Percentage of fish consumed.

- Diet.Vunk:

  Percentage of unknown/unclassified vertebrates in the diet.

- Diet.Scav:

  Percentage of scavenging activity.

- Diet.Fruit:

  Percentage of fruits consumed.

- Diet.Nect:

  Percentage of nectar/pollen consumed.

- Diet.Seed:

  Percentage of seeds/nuts consumed.

- Diet.PlantO:

  Percentage of other plant tissues consumed (leaves, stems, roots).

- Diet.Source:

  Source of the dietary information.

- Diet.Certainty:

  Certainty score for the diet data.

- ForStrat.Value:

  Primary foraging stratum/habitat.

- ForStrat.Certainty:

  Certainty score for the foraging stratum.

- ForStrat.Comment:

  Notes on foraging strategy.

- Activity.Nocturnal:

  Binary flag for nocturnal activity.

- Activity.Crepuscular:

  Binary flag for crepuscular activity.

- Activity.Diurnal:

  Binary flag for diurnal activity.

- Activity.Source:

  Source of the activity information.

- Activity.Certainty:

  Certainty score for the activity pattern.

- BodyMass.Value:

  Body mass value in grams.

- BodyMass.Source:

  Source of the body mass information.

- BodyMass.SpecLevel:

  Specificity level of the body mass record.

## Source

EltonTraits 1.0 database.
